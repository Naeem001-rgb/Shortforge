# Local Studio engine

> Historical browser-editor documentation. These interfaces were removed. See [current Studio setup](../../CONCAT.md).

**Historical implementation notes:** the editor-only routes and renderers described below were removed. This folder now retains shared media helpers and Scout caption/speech checks. Current editing launches the native Concat desktop application; see [the Concat guide](../../CONCAT.md).

This file describes the **legacy single-source export path**: `POST /api/export` in `routes.py`, whose FFmpeg command is built by `render.py`. The live timeline editor exports through `POST /api/editor/{clip_id}/export` in `editor_routes.py` / `editor_render.py` instead — see [EDITOR_BACKEND.md](EDITOR_BACKEND.md). Everything below about presets, caption timing and export notes describes the legacy route, which the dashboard no longer calls but which the integration tests still exercise.

Studio does **not** check footage rights. A clip's `license_status` is recorded metadata and nothing more: `require_editable()` in `engine/core/db.py` is an existence check that only confirms the project row is there, and no route consults rights before reading, editing or exporting. The original licence gate was deliberately removed on 2 October (`248bcbb`) — see AGENT.md §0 — so please do not reintroduce it as a side effect of some other change. What these routes genuinely require is a **source file**: `get_source()` answers 400 until the clip has a downloaded or uploaded source asset, which is why caption detection and the legacy export both refuse to run on a metadata-only clip. Rendering uses CPU H.264/AAC, 1080×1920, with one render at a time and FFmpeg progress stored in the job table. The packaged FFmpeg binary supports ASS in the integration test on this machine.

The current timeline editor offers local AI caption removal through RapidOCR and MI-GAN, with area selection, a one-second preview, cancellable processing, explicit apply, and undo. The AI repairs each frame separately while keeping the original frame rate. It can flicker or smear, and CPU processing can take hours. See [caption removal setup and limitations](CAPTION-REMOVAL.md). Legacy blur/cover/crop treatments remain supported by old saved projects and APIs; they are not presented as AI removal.

Ten presets live as editable JSON in `presets/`. ASS rendering implements color, outline, box, font size, position, word groups, pop/fade/rise animation, progressive word appearance, and karaoke fill. Gradient Pop uses a stepped per-word color blend. The dashboard uses locally bundled Inter; video subtitles use bundled DejaVu Sans 2.37, including its upstream license in `fonts/`. On each captioned export the font is copied into a local `fonts` folder and passed to FFmpeg's `fontsdir`, so Windows does not need DejaVu installed. The relative filter path handles spaces and Windows drive names without quoting problems. Some scripts outside DejaVu's coverage can still require an appropriate local fallback. The exported MP4 is the final preview of ASS styling.

Caption timing uses the source transcript for original audio, offset by trim start. For replacement/mixed narration, it reads only the selected voiceover's timing sidecar. The voiceover is captured when export is requested, so another generation finishing while the export waits cannot change its audio. Changed text or unavailable timestamps uses proportional timing across the voice duration, then clips those words to the selected video length. A long voice is never squeezed into a shorter caption timeline.

Export returns `timing_note`, `audio_note`, `caption_note` and `trim_note` in the queued job before rendering, then updates the notes on completion. `audio_note` states the exact seconds of narration that will be cut or the silent/original-audio tail that will remain. Excess narration is trimmed to the chosen video length and short narration is padded; the UI should display these notes. Changed caption text with Original audio also explicitly states that the narration remains unchanged. Source, voice and export durations plus output dimensions are included for the UI. There is no automatic upload.

Automated tests check exact word-count tolerance/retries, narration-source separation, attribution, the missing-source gate on export and caption detection, consent/reference cleanup, subtitle injection escaping, generated FFmpeg commands, and real MP4 renders for blur/cover/crop, silent sources, mixed audio and replaced audio. Optional Tesseract and speech-model inference are not exercised without their installed dependencies.
