# ShortForge
<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
User-specified: React, TypeScript, Vite with hand-written CSS; Python FastAPI, SQLite; Chrome MV3 extension.

## Users and purpose
A student with no budget builds narrated videos on a CPU laptop. ShortForge combines discovery, a multitrack video editor, imported voiceovers and music, timed text, animation, and export in a local workspace. Scripts and voiceovers are created externally; the user explicitly removed script rewriting and AI voice creation from the app interface.

## Constraints
Free software first. No paid dependencies required. Local Linux machine detected; Windows startup also supplied. API keys remain server-side. Credits are optional in discovery; reuse permissions remain recorded. The user requested both whole-soundtrack removal and separation of vocals from background music and authorized installation of the local separation runtime/model. Audio separation is approximate and may leave artifacts; it does not generate speech. Original files stay intact when timeline items are removed. Concat saves exports locally. YouTube channel Settings and backend services remain, but the previous editor's publishing interface was removed; Concat has no publishing handoff. Export alone never posts.
