# ShortForge
<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
User-specified: React, TypeScript, Vite, Tailwind; Python FastAPI, SQLite; Chrome MV3 extension.

## Users and purpose
A student with no budget builds narrated vertical videos on a CPU laptop. ShortForge combines discovery, script editing, captions, voiceover, and export in a local workspace.

## Constraints
Free software first. No paid dependencies required. No large model downloads without the user choosing them. Local Linux machine detected; Windows startup also supplied. API keys remain server-side. Credits are optional in discovery per the latest request; reuse permissions remain recorded. Local voice cloning is optional and requires a voice reference with permission. Caption cleanup is approximate blur, cover, or crop. Export MP4 and provide a manual YouTube Studio handoff.

## Brand commitments
The supplied spec requests a refined Apple-like interface, light/dark/system themes, Inter, a single blue accent, Lucide icons, generous spacing, and a three-pane editor. Research Dribbble, 21st.dev, and Mobbin without copying designs.

## Open decisions
Channel topic and language asked in one optional first-run question. Working assumption: English narrated facts/stories, editable in Settings. Default scout limits: 5,000 likes, 10,000 views, 30 results.
