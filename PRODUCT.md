# ShortForge
<!-- impeccable:product-schema 1 -->

## Platform
web

## Stack
User-specified: React, TypeScript, Vite, Tailwind; Python FastAPI, SQLite; Chrome MV3 extension.

## Users and purpose
A student with no budget builds narrated videos on a CPU laptop. ShortForge combines discovery, a multitrack video editor, imported voiceovers and music, timed text, animation, and export in a local workspace. Scripts and voiceovers are created externally; the user explicitly removed script rewriting and AI voice creation from the app interface.

## Constraints
Free software first. No paid dependencies required. Local Linux machine detected; Windows startup also supplied. API keys remain server-side. Credits are optional in discovery; reuse permissions remain recorded. The user requested both whole-soundtrack removal and separation of vocals from background music and authorized installation of the local separation runtime/model. Audio separation is approximate and may leave artifacts; it does not generate speech. Original files stay intact when timeline items are removed. Export MP4 and provide a manual YouTube Studio handoff.

## Brand commitments
The user-supplied Nexus dashboard and brand guide set the visual direction: compact white panels on a subtle cool-gray gradient, a narrow navigation rail, violet #5347CE primary actions, lavender #887CFD, and supporting blue #4896FE and teal #16C8C7. Use the Apple system/SF Pro font where available and bundled Inter elsewhere, Lucide icons, and equivalent light/dark/system themes. The library uses five compact cards per desktop row, with inset images, distinct violet-gray borders, and generous card gutters. The removed creative-workflow footer stays absent. Studio follows the requested CapCut-style editing arrangement: media bin, central player, right inspector, and multitrack timeline below; it replaces the previous Script/Voice step workflow. Preserve real ShortForge content and avoid claims of complete CapCut parity.

## Open decisions
Channel topic and language asked in one optional first-run question. Working assumption: English narrated facts/stories, editable in Settings. Default scout limits: 5,000 likes, 10,000 views, 30 results.
