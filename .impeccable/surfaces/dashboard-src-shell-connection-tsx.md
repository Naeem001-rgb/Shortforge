# Private workspace connection

Mode: Operate. This is a connection state within the existing ShortForge dashboard, not a new visual identity.

THESIS: A nontechnical user can reach their own Library through the normal launcher without exposing it to unrelated websites, extensions or local HTTP clients.

OWN-WORLD: Inherit the paper-and-lime palette, bundled fonts, Lucide icons and shared buttons/fields/notices from PRODUCT.md, DESIGN.md and the dashboard. No new imagery, design system, marketing treatment or paid service.

STORY: The launcher opens a private one-use link; the dashboard consumes it and removes it from the URL. Cold/expired windows explain how to reopen or retry. Chrome users can connect Scout in Settings. Explicit Studio links wait for a real launch action.

FIRST VIEWPORT: A readable heading, concise recovery instruction and retry action; optional manual connection is secondary. Loading and errors are distinct. No Library content is requested by an unconnected window.

FORM: A narrow, responsive content column using existing form controls, with generous spacing and a warm paper background. Settings adds one small connection section. Desktop/mobile, keyboard access, errors and reduced motion follow the incumbent system.
